# Changelog

All notable changes to Xender Lite are documented here.

## [2.0.0] - 2026-10-08

### Added

* Updated desktop app release for Windows
* Improved local browser dashboard with files, devices, settings, and logs
* Enhanced LAN device communication flow
* Better app configuration and persistent settings handling
* Recent-file tracking and local app data management
* QR code connectivity support for quick pairing
* WebView-based desktop shell experience
* Node.js 22 compatibility updates and project modernization

### Improved

* Refined local and LAN file-sharing workflows
* Better organization of app routes and static assets
* Improved handling of user-specific local application storage
* Cleaner project structure and documentation updates

### Security

* Hardened local app data handling
* Added validation for application configuration and file paths
* Improved app-level safeguards around local WebUI and data access

### Release

Xender Lite v2.0.0 is the next major release, focused on a more complete local-sharing experience and improved Windows app structure.

## [1.0.0] - 2026-09-25

### Added

* Initial stable release
* File browsing
* Image, video, and audio support
* File transfer
* Local WebUI
* LAN server
* Socket.IO communication
* QR code network connection
* Windows WebView application
* Application settings
* Windows installer
* Windows uninstaller

### Security

* Added HTTP security protections
* Added input and file-path validation
* Improved handling of application data

### Release

Xender Lite v1.0.0 is the first stable release.
